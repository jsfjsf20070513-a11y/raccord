## 方向一 «La rotonde»(石厅)

`direction-1-la-rotonde.png / .html`

**机制(≤80字)**:俯视穹顶下的石厅地面。拖动定向,松手后摆动弦线**钉死在屏幕上**;刻线地面连同标题、页码作为一个刚体缓慢旋转。你发现标题歪了——是页面在转,不是摆。

**移动端 390×844**:同为正俯视,紧裁到内环;弦线偏竖直走向,地面刻线在竖幅中旋转;标题倾斜同理。触控拖动定向,构图独立,非桌面缩小。

**四态**:
- dormant:地面昏暗,球静悬中心,无弦线,刻线不转
- gesture:从球拖出,方向发丝线跟随指尖
- released:弦线开始往复,地面开始不可察觉的旋转;释放刻痕留在地面
- revealed:地面与排版已转过明显角度,释放刻痕与活弦线张开夹角,T+58 MIN

**最可能失败成**:转盘装饰/加载动画——若转速失当,整屏旋转沦为特效甚至致晕;排版倾斜若过早被注意,揭示变成噱头。

## 方向二 «Les deux verticales»(双垂线)

`direction-2-les-deux-verticales.png / .html`

**机制(≤80字)**:平视,人身尺度直面巨球。侧向拖开、放手,摆动平面渐渐转向侧对你——摆幅像在"合拢"。释放时落下一条虚线铅垂,与房间自己的垂线缓慢分歧:两条垂线,哪条是真的直?

**移动端 390×844**:竖幅近景,球占上二分之一,地平线下移;拖动为横向弧线;两条垂线的分歧在竖幅中更修长。独立构图。

**四态**:
- dormant:球静悬,单一地平发丝线,一条垂线
- gesture:横向拖动,球荡开,钢丝绷紧
- released:摆全幅摆动,虚线铅垂钉在释放方位
- revealed:摆近乎侧对(视幅收窄),房间垂线与释放垂线张开 Δ 7.4°,扫过椭圆残迹

**最可能失败成**:被误读为"摆在衰减/装置坏了"(视幅收窄像能量损失);或球太美而沦为静物壁纸,分歧线无人注意。

## 方向三 «La ligne fidèle»(忠实的直线)

`direction-3-la-ligne-fidele.png / .html`

**机制(≤80字)**:伏案看一页帐格纸。你画下一笔——即释放;此后墨线一遍遍重描你那一笔,永远笔直、永远同轴。而纸自己的格线与页边距缓慢转走,每一遍在页边留下一道见证刻痕,扇形展开:转的是纸,不是线。

**移动端 390×844**:竖幅纸卷,墨线纵向;格线横向缓慢剪切;见证刻痕扇在上端页边累积。滚动即翻阅记录,独立构图。

**四态**:
- dormant:空帐格纸,一个原点圈
- gesture:指尖画一笔,墨迹跟随
- released:线按原轴重描,格线开始漂移
- revealed:格线已明显偏转,页边见证扇 + PASSE 27 · T+42 MIN,离开再回来扇更宽

**最可能失败成**:万花尺/生成艺术玩具(若线迹装饰化);或与 Carnet 世界的纸面材质串味,像第一章的一页而非新章。
