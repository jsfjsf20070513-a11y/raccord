# 三世界合宪审判 · 2026-07-13

> 本轮只判决，不改实现。“删除”默认指退出世界核心与主导航，不等于本轮销毁数据、路由或安全管线。

## 审判范围与证据

- 宪法：[`product-constitution.md`](product-constitution.md)
- 当前实现：本地真实 SPA，未向页面注入审计 DOM。
- Desktop：`1440 × 900`；Mobile：`390 × 844`。
- 路径：Enter → 三世界首页；PLAN Atlas；Carnet Archives / Registre；Limite Vocabulary / Assistant。
- 当前截图：`/tmp/math-constitution-audit-2026-07-13/`，共接受 14 张；`02b-plan-home-full.png` 因 full-page 捕捉丢失延迟内容而拒绝，不作证据。
- 未登录状态阻断 Vocabulary 与 Assistant 的核心流程，因此这两页只能审判入口与信息架构，不能审判登录后的任务质量。

## 总判决

**Enter 通过本轮视觉与形式审查；三个世界的视觉谱系与当前构图值得保留；三个世界的中心对象、部分交互与当前功能归属仍未合宪。**

当前产品已经拥有难得的视觉资产：三个入口像三件不同器物，三套字体、材质、空间与响应语法互不换皮，双端也不是简单压缩。问题不在壳，而在壳里仍由旧网站功能决定内容：PLAN 被资源目录占据，Carnet 被浅定理索引与留言占据，Limite 把仪器、SRS 与 AI 并列为三个工作站。

## 流程逐步审判

### 1. Enter · Desktop — 健康，保留

- 黑色坐标场、巨幅标题、三件等量器物形成明确节奏；可不靠说明文字理解“进入三个异质空间”。
- 三张入口不是同一截图换色；PLAN、Carnet、Limite 已有不同材料行为和视觉密度。
- 三个入口均是有明确可访问名称的 `button`，页面无横向溢出。
- **判决：保留。** Enter 是目前最完整的产品，不承担解释三个世界的义务。

证据：`01-enter-desktop.png`

### 2. PLAN 首页 · Desktop — 视觉健康，产品核心待审

- 工程纸、巨幅 PLAN ℝ、坐标与真实数字形成清晰封面，留白不是廉价空白。
- 但首屏的主要信息仍是班级身份与 `30 / 24 / 77` 三个统计，用户没有面对一个可持续操作的对象。
- 页面下半部最终导向 Atlas 与 Chantier，因此它现在是一张优秀封面，不是一个完整世界。
- **判决：保留视觉谱系；核心进入试验。** 统计降为背景信息，不能继续充当存在理由。

证据：`02-plan-home-desktop.png`

### 3. PLAN Atlas — 工具健康，降级

- 左侧八区、右侧单区 master/detail 的层级干净，77 条资源没有重新铺成卡片墙。
- 但其本质仍是经过美化的资源索引：切换分类、查看链接，没有产生新的关系、模型或判断。
- **判决：降为工具层。** 数据与页面可以保留，但 Atlas 不再定义 PLAN，也不默认占据世界主导航。

证据：`03-plan-atlas-desktop.png`

### 4. Carnet 首页 · Desktop — 当前最强世界，保留形式

- 双页、中轴、发丝线、中文定理与法文书页形成真正不同的时间感与阅读姿势。
- 一页只呈现一个定理，文字密度克制；在本轮视觉审查里，美本身构成了停留理由，但真实停留与回访行为尚未验证。
- 左页的 `Mémoire de classe` 与通用引文仍像气氛占位，右页每日定理也只有定义、公式和极短批注，材料密度没有追上形式。
- **判决：保留整套书页形式；中心材料进入试验。** 未来中心可以是证明、照片、信件、声音或其他真实材料，不固定为每日定理。

证据：`04-carnet-home-desktop.png`

### 5. Carnet Archives — 版式健康，内容降级

- 目录与阅读页并置，视觉上没有普通卡片或手风琴堆叠；阅读对象能留在一页内。
- 但 24 条定理目前主要是标题、定义、公式和一句批注，尚不足以形成值得反复近读的档案。
- **判决：降为材料库。** 只有加入证明过程、来源、草稿、反例或多种观察镜片后，才有资格回到世界核心。

证据：`05-carnet-archives-desktop.png`

### 6. Carnet Registre — 视觉健康，来源与机制违宪

- 现有六条内容排版克制，但代码证据显示其中五条是 `editorial-*` 编辑样例，只有一条是有 Solana provenance 的已恢复记录；当前界面却把它们等量呈现为班级档案。
- 新写入仍是无锚点留言；它不会改变照片、证明、史料或其他共同对象。
- **判决：留言入口退出核心并停止扩张；既有内容先做来源审计。** 有明确 provenance 的记录可以进入历史档案；编辑样例必须显式标注为样例，或退出档案。若未来重做，发言必须锚定具体材料，并承担补证、纠错或另一种解释。

证据：`06-carnet-registre-desktop.png`

### 7. Limite 首页 · Desktop — 视觉保留，结构拆分

- 暗场、朱红信号和收敛仪器是三世界里最明确的“可触摸物”；pointer 激活后 `n = 29`、误差进入 `1.86E-9`，且材质停在 `resting`，响应连续而非永续表演。
- 但仪器下方的 Vocabulary 与 Assistant 与收敛对象没有内在关系。二者只是因为“工具感”被放进同一房间。
- **判决：保留暗场、仪器、pointer 响应与沉睡机制；两个工作站从世界核心拆出。** “接近边界”能否成为完整认知体验，仍属于试验而非既成结论。

证据：`07-limite-home-desktop.png`、`14-limite-instrument-active-desktop.png`

### 8. Limite Vocabulary — 降级，登录后体验未审

- 未登录时只有标题、同步说明和登录入口，大片空场没有中心对象；登录链接在 Mobile 实测仅 `53 × 24px`。
- SRS、词库和同步管线有真实工具价值，但现有证据不足以让它成为世界。
- **判决：降为独立工具。** 保留数据与学习管线，不再以 `01 Vocabulaire` 定义 Limite。

证据：`08-limite-vocabulary-desktop.png`

### 9. Limite Assistant — 从核心删除，登录后体验未审

- 当前入口的主要内容只有“Assistant / Connexion requise”，要求用户先理解并主动寻找一个通用 AI 服务。
- 它没有提供本站独有对象，也没有在入口处证明为何必须存在于 Limite。
- **判决：退出世界主导航与独立工作站定位。** Worker 与安全管线保留；AI 以后只在具体对象需要识别、解释、校验或模拟时局部出现。

证据：`09-limite-assistant-desktop.png`

### 10. Enter · Mobile — 健康，保留

- 标题完整，第一件器物完整出现并露出第二件，形成自然纵向翻阅；`scrollWidth = innerWidth = 390`。
- 大卡片本身提供足够触控面积，不依赖细小文字才能进入。
- **判决：保留。**

证据：`10-enter-mobile.png`

### 11. PLAN · Mobile — 构图健康，核心问题同桌面

- 独立 `PLAN / ℝ` 构图、数据尺与两条大入口清楚，没有把桌面双栏硬压进手机。
- 但页面仍以统计和两个工具入口结束，是优秀目录封面。
- **判决：保留移动形式；内容核心进入试验。**

证据：`11-plan-home-mobile.png`

### 12. Carnet · Mobile — 健康，保留形式

- 单页 folio 顺序自然：今日材料先完整出现，记忆页从下方进入；中文标题、公式与页间留白保持节奏。
- 内容深度仍受同一条“浅材料”限制。
- **判决：保留移动形式；替换或深化中心材料。**

证据：`12-carnet-home-mobile.png`

### 13. Limite · Mobile — 构图健康，信息架构拆分

- 仪器成为单一纵向主体，响应区域和两个入口没有横向溢出。
- 但顶部导航使用 `8px` 文字；非当前项实测为 `rgb(122,117,108)`，在暗底上有低可读性风险。世界切换符号虽高 `44px`，宽仅 `7px`。
- **判决：保留仪器构图；拆走 Vocabulary / Assistant；重做移动导航的字号、对比度与触控宽度。**

证据：`13-limite-home-mobile.png`

## 四类最终清单

### 保留

- Enter 的黑色坐标场、标题节奏与三件入口器物。
- 三套当前视觉谱系，以及它们不同的时间感、材料行为和交互语法。
- Desktop / Mobile 独立构图与独立挂载。
- PLAN 的工程纸与制图骨架。
- Carnet 的双页 / 单页 folio 形式。
- Limite 的暗色仪器、pointer 驱动与沉睡机制。
- 已确认来源的真实数据、安全管线与 SRS 核心。

### 降级

- PLAN Atlas：公共工具，不再定义世界。Chantier 本轮未单独审判，不进入最终清单。
- Carnet 的 24 条定理：材料库，等待深化。
- Vocabulary：独立工具，不再是 Limite 的主工作站。
- 登录、账号、统计、搜索：服务层，默认隐退。

### 试验

- PLAN：寻找一个真正能被构造、扰动或比较的中心对象；不预设学科。
- Carnet：每一期围绕一个清晰中心材料或边界明确的材料组，并允许时间、来源或生成过程成为第二观察镜片。
- Registre：先完成来源审计与显式标注；只让有 provenance 的记录成为历史档案，编辑样例不得伪装成史料。
- Limite：保留现有视觉与响应机制，继续验证“接近边界”能否成为完整体验；先让一件仪器成立，再决定是否需要其他内容。
- AI：只测试局部能力，例如指出证明缺口、生成可反驳关系或解释一次具体失败。

### 删除

- 通用 Assistant 作为世界入口和主导航项目。
- 新留言作为 Carnet 的核心参与机制。
- 资源数量、词库数量、统计数字作为世界存在理由。
- 因为已经有代码，就把功能固定分配给某个世界的思路。
- 三世界共享同一功能模板后仅换色换字体的任何方案。

## 可访问性与证据限制

### 已确认

- 七个 Desktop 路径均为 `1440px` 宽且无横向溢出；四个 Mobile 关键页面均为 `390px` 宽且无横向溢出。
- Enter 三个入口有明确按钮名称；世界导航有明确 `aria-label`。
- Mobile 顶部导航多数目标高度为 `44px`，但世界切换项宽度和登录入口不足 `44px`。
- Limite Mobile 顶部世界导航仅 `8px`，存在明显可读性风险。
- `/vocabulary` 当前 DOM 存在两个嵌套 `main` landmark，登录链接仅 `53 × 24px`；Assistant 的当前 DOM snapshot 也显示同类双层页面壳，需代码复核。
- 当前审计会话未捕获 console warning / error。

### 尚未确认

- 未登录，无法审计 Vocabulary 的完整 SRS、Assistant 对话、错误恢复和真实任务完成率。
- 截图不能证明完整键盘顺序、焦点可见性、屏幕阅读器朗读或 WCAG 合规。
- 本轮没有审判具体新世界题材，也没有把调研项目映射到现有三世界。
