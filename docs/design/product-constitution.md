# Raccord 产品宪法 · v2.0

> 2026-07-29 生效。
> 本文件是产品意图正本：它规定作品如何生长、什么可以进入核心、什么必须退后。它不冻结某一期的题材、人物、世界数量或视觉表面。

## 序言

Raccord 是一件持续生长的作者数字作品。

它不是功能集合，也不以班级需求、活跃度或工具数量证明存在。访问者可以因美进入，在一个世界中遇到无法由静态页面替代的问题，并因选择、时间、材质或未完成之物留下余韵。

世界是这件作品的核心词汇。章节不是对世界的替代，而是世界生命中发生的一次事情。

## 第一条：作品、世界与章节

世界持续存在，拥有自己的时间、记忆、气候、材料伦理与行为边界。它不只提供地点，也会积累历史，并在没有章节发生时继续以静默、环境与痕迹活着。

章节是世界中发生、并可能改变世界的一次事件。它围绕一个核心矛盾、思想化身或不可替代的相遇，使世界的法则被看见、被触碰或被改写。

一个世界可以经历多个章节；一个章节可以只发生在一个世界，也可以自然穿过多个世界。不得为了维持“三界结构”强迫章节分幕，也不得为了增加章节而把世界降成可替换的主题皮肤。

为了描述信息结构，可以把世界理解为作品的空间关系、把章节理解为作品的时间次序；这只是导航比喻，不是对世界本体的切割。

## 第二条：世界不是栏目

世界不是频道、知识分类、功能部门或配色方案。遮住名称与配色后，如果一个世界不能通过时间感、空间结构、材料行为与交互语法被辨认，它就尚未成立。

PLAN、Le Carnet、Limite 是当前作品中的三个世界：

- PLAN 倾向秩序、数学、构造与理性；
- Le Carnet 倾向语言、记忆、哲学与时间；
- Limite 倾向飞行、边界、风险与远方。

这些倾向是引力，不是永久分类。世界可以改变题材、媒介与生命阶段，可以沉睡，也可以被新的章节重新理解。现成代码和既有内容不得反过来决定世界必须成为什么。

每个世界应逐渐显出少数可辨认的不变量。若时间法则、材料伦理、空间关系与行动逻辑全部被替换，应承认一个新世界诞生，而不是沿用旧名。具体不变量必须从多次真实作品中长出，不由宪法提前写死。

“世界”保留为公开作品语言；不得用“模块、频道、栏目、产品线”等词替代它。

## 第三条：章节不是专题

章节不是人物生平、知识课程、功能合集或三张风格页面。

每章应守住一个清晰的关系中心：

1. 一个真实矛盾或问题；
2. 一种访问者无法置身事外的关系；
3. 一种离开后仍成立的理解、记忆、对象变化或未完成状态。

关系中心可以是一件对象，也可以是一片场、一次等待、一段声音或一个不能行动的时刻。主导行为可以是构造、选择、驻留、聆听、放弃，甚至只是逐渐意识到。

人物可以缺席，世界不能替章节代写意义。去掉人物姓名、标题和说明后，若相遇不再成立，这一章就只是内容包装。离开后的余韵也不等于必须写入持久化状态。

## 第四条：美具有独立价值

美不是功能完成后的装饰，而是作品给予人的经验。字体、比例、留白、材质、光、声音和运动都可以成为内容。

一次访问不必生产数据或完成任务，但必须真正改变访问者的感知、理解、记忆，或改变世界中的对象；两者皆无，体验才是不成立。

克制不是清汤寡水。它允许丰盛、华美与趣味，但要求每一件留下的东西不可替代。

## 第五条：关系中心与主导感知

每个章节场景应有一个清晰的关系中心与主导感知。不能直接加强中心的说明、导航、统计和工具必须延后、隐退或删除。

交互不是给静态画面添加动画。若访问者能够行动，动作必须改变关系、约束、时间或对象；若章节要求等待、沉默或失去行动权，不能为了“可玩”强加拖拽和按钮。普通 hover、拖拽展示与无后果的特效不能独立构成章节。

新增不是累加。每增加一件东西，必须说明它替代了什么。

## 第六条：差异来自内在法则

世界之间的差异必须进入时间、空间、材料、文字密度和行动法则，而不只是换色、换字体、换背景或换人物。

同一世界中的章节应继承可辨认的世界法则，同时提出不同的矛盾与相遇；不得只复制前一章的中心对象、交互结果或成功公式。

世界可以共享 Raccord 的最小书脊、转场礼仪、比例纪律、真实数据和必要底层能力，但核心构图、材料行为与行动法则不得套用同一模板。

第一章《Le ciel de Poincaré》的 seed / memory / scar 是该章的命运，不是全站模板。

## 第七条：数字媒介必须不可替代

章节必须说明为什么它需要数字媒介。

不可替代性可以来自：

- 世界能感知访问者的行动；
- 时间在离开页面后继续；
- 一次选择永久改变后续；
- 材质能够积累、衰减或记忆；
- 同一对象在不同世界法则下改变意义；
- 访问者所在的参照系被世界反过来揭示。

如果一张海报、插画或一段说明已经表达了全部内容，它可以进入视觉档案，但不足以成为完整章节。

## 第八条：思想化身只通过法则复活

数学家、哲学家、工程师、飞行者与神话人物可以作为思想化身存在。复活的是其问题、方法与精神张力，不是假装还原人物本人。

构造可以成为回答，时间可以成为反驳，材料可以成为记忆，失败、不可预测与沉默也可以成为语言。

聊天框、人物卡、生平介绍、仿古口吻和伪名言都不是默认形式。历史原文必须可核验；思想转述必须忠于原意；作品语言不得冒充人物原话。

## 第九条：后果与世界生命

世界可以在人离开后继续，但必须有作品理由。持续必须来自诚实的时间或状态关系，不用无意义的后台动画伪造“世界一直运行”。

重复访问应逐渐显出证据，而不是简单重复首访动画。变化可以微弱，但必须可辨认、诚实且与访问者此前的动作有关。

不构成独立章节、但真实体现世界法则的环境现象、材质行为、天气、仪式与日常痕迹，可以作为世界生命存在。它们既不是功能，也不必被包装成章节。

若视觉 QA、测试和性能全部通过，而作者与不知情访客仍只记得“一个动画”或“一个可拖动的东西”，作品原型仍然失败。

## 第十条：工具与档案各归其位

AI、留言、背词、搜索、账号和统计都没有天然核心地位。

- 有实际用途但不构成相遇的能力进入**工具层**；
- 曾经承担核心探索、后来退出当前作品的实验进入**实验档案**；
- 尚未通过作者与访客闸门的方向只作为**可撤销原型**存在；
- 只有通过章节闸门的作品进入正式章节。

工具不得伪装成世界，档案不得重新统治当前章节，已实现的功能不得因沉没成本获得入口。

## 第十一条：Enter 是门槛

Enter 是进入世界的序章作品，不是普通首页、功能导航或章节列表。

它负责让访问者感到世界的存在，并允许选择进入时的关系。章节、工具与实验档案必须可达，但访问方式不得破坏 Enter 的门槛感，也不得与三件世界器物争夺首屏。

Enter 可以演化，但不得因信息架构压力被填成门户网站。

## 第十二条：不同身体关系分别成立

同一作品在不同设备与身体距离中必须分别成立，而不是机械缩放同一构图。

它必须重新回答：手指、指针或键盘如何接触对象，身体距离如何改变，时间证据如何被看见。

无障碍不是作品之外的说明层。不同输入方式、减弱动态与语义状态必须让同一核心关系成立。当前 Desktop / Mobile 的具体工程边界由开发约定规定，不写成永久美学宪法。

## 第十三条：作品闸门

候选章节进入 canon 前，必须证明：

1. 命题与关系中心成立；
2. 数字媒介不可替代；
3. 作者亲自体验后仍认可；
4. 援引的历史、数学、物理或其他外部事实诚实；
5. 视觉、输入方式、性能与无障碍不背叛核心关系；
6. 获得明确的 canon 决定。

工程通过不等于作品通过，漂亮截图不等于相遇成立。未获认可前，不建立正式入口，不把候选机制写成全站事实。

具体制作顺序、访客测试与工程验收属于可演化的创作协议，不写成永久宪法。

## 宪法审查

任何新页面、功能、世界或章节提案，都必须回答：

1. 人具体面对什么？
2. 他唯一最重要的动作是什么？
3. 世界如何回应，而不是界面如何反馈？
4. 离开后留下了什么？
5. 为什么必须以数字媒介和这个世界存在？
6. 为它进入，应当删除、沉睡或归档什么？

六问成立，才可进入核心；真实体现世界法则但不构成章节的现象，留在世界生命中；有用但不构成相遇的能力，降为工具；方向成立但证据不足，做可撤销实验；答不出来，删除。

## 修宪

宪法可以改变，但不能被一次实现顺手改写。修宪必须来自明确的作者判断，并同步更新本文件、`CONTEXT.md` 与 `AGENTS.md`。

旧设计稿、旧代码和旧研究记录只能证明“曾经怎样”，不能否决新的拍板。
