# 60 Second Demo Video Script

## 0-10s: Who I Am

Hi, I am a freshman mathematics student at the Suzhou campus of Renmin University of China Sino-French Institute. I am interested in mathematical modeling, AI-assisted development, and building practical product prototypes for hackathons.

## 10-20s: What The Project Is

This project is MathClassWebsite, a deployed class website and public hackathon showcase. The original site helps organize class-facing content, while the `/hackathon` page explains the product, technology stack, my role, and development process for reviewers.

## 20-40s: Live Demo Walkthrough

First, I open the live demo and show the homepage, which keeps the original class website purpose. Then I enter the Hackathon Showcase page. In about 30 seconds, a reviewer can see the problem, solution, key features, tech stack, my contribution, AI-assisted workflow, roadmap, and contact placeholders. I also show the public GitHub repository, where the README, deployment notes, screenshot checklist, and application materials are organized for submission.

## 40-50s: Tech Stack And AI-Assisted Workflow

The frontend is built with React and Vite, with Supabase used for backend data features such as authentication and content storage. I used AI tools to accelerate coding, debugging, refactoring, deployment notes, and documentation, while I stayed responsible for defining the problem, checking the output, and making final product decisions.

## 50-60s: Closing And Next Step

This is a small but complete student-builder project: deployed, documented, and public on GitHub. My next step is to use it in Dev3pack, AdventureX, and other hackathon applications, and to keep improving the prototype through real team collaboration.
