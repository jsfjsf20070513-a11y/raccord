# Screenshots

This folder hosts judge-facing screenshots linked from the main
`README.md` and from the hackathon submission. Screenshots that
contain identifying class information are kept outside this public
repository.

## How to refresh

1. Run a fresh production build (`npm run build && npm run preview`)
   so the live URLs render against an up-to-date bundle.
2. Use the deployed production URL or the local production preview;
   never use a `npm run dev` screenshot — Vite dev banners and
   port-5173 artefacts are unprofessional in submissions.
3. Keep every screenshot free of email addresses, admin-only data,
   tokens, or draft content that should not be public.
4. Re-export at 2× scale (Retina) and trim to a 16:10 ratio when
   reasonable so the README thumbnails align.

## Naming convention

- `homepage-desktop.png` — title page at 1440×900.
- `web3-profile-flow.png` — connect → sign → anchor on `/web3-profile`,
  with the resulting Solscan transaction visible.
- `hackathon-showcase-desktop.png` — the hackathon entry page hero.
